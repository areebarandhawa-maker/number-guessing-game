# number-guessing-game
Advanced Python Number Guessing Game with difficulty levels, hints, and statistics.
🎮 Advanced Python Number Guessing Game
📌 Project Description

The Advanced Python Number Guessing Game is a console-based interactive application developed using Python. The game challenges users to guess a randomly generated secret number within a limited number of attempts.

The application offers three difficulty levels: Easy, Medium, and Hard. Each level provides a different number range and maximum guessing attempts.

It also includes an interactive hint system, input validation, replay functionality, and session statistics to track player performance.

✨ Features
🎯 Three difficulty levels: Easy, Medium, and Hard.
🎲 Random secret number generation.
🔢 Limited attempts based on difficulty.
💡 Helpful hints (Too High / Too Low).
✅ Input validation and error handling.
🏆 Best score tracking.
📊 Session statistics (Games Played and Games Won).
🔄 Replay functionality.
🖥️ Simple and user-friendly console interface.

🚀 How to Run the Project
Install Python 3.x on your computer.
Download or clone this repository.
Open the project folder in VS Code or any Python IDE.
Run the following command:
bash
python number_guessing_game.py

Select your preferred difficulty level.
Start guessing the secret number!
